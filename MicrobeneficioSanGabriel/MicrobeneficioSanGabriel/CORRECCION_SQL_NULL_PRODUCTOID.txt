CORRECCIÓN SqlNullValueException - ProductoId histórico

Causa:
Pedido.ProductoId y MovimientoInventario.ProductoId deben aceptar NULL para conservar
registros históricos después de eliminar un producto. No deben tener el atributo [Required],
porque EF Core podría tratarlos como obligatorios al materializar entidades.

Cambios realizados:
- Eliminado [Required] de Pedido.ProductoId.
- Eliminado [Required] de MovimientoInventario.ProductoId.
- Configuración opcional explícita en ApplicationDbContext.
- Validación de selección de producto mantenida en los controladores.
- El listado de movimientos muestra correctamente registros históricos.

No se necesita una nueva migración si ya se aplicó:
20260728030000_PermitirEliminarProductosConHistorial

Después de abrir el proyecto:
1. Cerrar la aplicación en ejecución.
2. Eliminar las carpetas bin y obj si existen.
3. Limpiar y recompilar la solución.
4. Ejecutar nuevamente.
